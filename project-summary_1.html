1

ออกแบบหน้าเว็บด้วย Claude AI

บอกความต้องการให้ Claude สร้างหน้าเว็บ HTML ครบในไฟล์เดียว มีเมนูแดชบอร์ด รายการอุปกรณ์ เบิก-จ่าย ประวัติ และจัดการผู้ใช้งาน

🤖 Claude AI 📄 HTML + CSS + JS
2

สร้างฐานข้อมูลด้วย Supabase

สมัคร Supabase (ฟรี) สร้าง Project แล้วรัน SQL เพื่อสร้าง 3 ตาราง ได้แก่ items (อุปกรณ์), transactions (ประวัติเบิก-จ่าย), users_list (ผู้ใช้งาน) พร้อมตั้งค่า Row Level Security

🗄️ Supabase 📊 PostgreSQL SQL Editor
3

เชื่อมต่อเว็บกับฐานข้อมูล

นำ API Key (anon key) และ Project URL จาก Supabase ใส่ในโค้ด JavaScript เพื่อให้เว็บดึงและบันทึกข้อมูลได้จริง ข้อมูลไม่หายเมื่อ refresh

🔑 Supabase API Key 🔗 REST API
4

อัปโหลดเว็บขึ้น GitHub

สมัคร GitHub สร้าง Repository ใหม่ แล้วอัปโหลดไฟล์ index.html ขึ้นไป เพื่อใช้เป็นแหล่งเก็บโค้ดและเชื่อมกับ Vercel

🐙 GitHub 📁 Repository
5

Deploy เว็บขึ้น Vercel (ได้ URL จริง)

สมัคร Vercel เชื่อมกับ GitHub แล้ว Deploy ได้ URL ที่ใช้งานได้ทันที เช่น 1-henna-alpha.vercel.app ทุกครั้งที่แก้ไขโค้ดใน GitHub เว็บจะอัปเดตอัตโนมัติ

▲ Vercel 🌐 URL สาธารณะ
6

เพิ่มระบบแจ้งเตือน Telegram

สร้าง Telegram Bot ผ่าน @BotFather รับ Token และ Chat ID แล้วสร้าง Cloudflare Worker เป็นตัวกลางส่งข้อความ (แก้ปัญหา CORS) เมื่อมีการเบิกหรือเพิ่มสต็อก บอทจะแจ้งเตือนทันที

✈️ Telegram Bot ☁️ Cloudflare Worker แจ้งเตือนอัตโนมัติ
7

นำเข้าข้อมูลกำลังพล 136 คน

อ่านข้อมูลจากไฟล์ Excel บัญชีรายชื่อกำลังพล สร้างเป็น SQL แล้วรันใน Supabase SQL Editor เพิ่มรายชื่อเข้าระบบครบ 136 คนพร้อมกัน

📊 Excel 🗄️ Supabase SQL 136 กำลังพล
